Daily CI run: API tests →

Runs automatically every day on GitHub Actions against the live REST API.
Why the UI tests don't run in CI: the practice site protects its web pages with a Cloudflare "verify you are human" check that blocks cloud-hosted browsers such as GitHub's runners. The API tests aren't affected, so they run live in CI. The full suite runs from a local machine, and its report is published here with its date. Getting past a bot check would defeat its purpose, so the suite doesn't try.
