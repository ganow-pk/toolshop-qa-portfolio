# Exploratory testing

Automated checks confirm what we already expect. Exploratory testing finds what we didn't think to expect. Both are part of how I test.

Sessions here follow **Session-Based Test Management (SBTM)**:
- **Charter:** a one-line mission, written before the session, that says what to explore and what to look for.
- **Time box:** a fixed, uninterrupted session (usually 45–90 minutes).
- **Session report:** notes, bugs, open questions, and how the time was split, written during and right after the session so the work can be reviewed.
